\begin{abstract}
Recognizing algorithmically equivalent code written in different programming languages remains a fundamental challenge in multi-language introductory programming courses.Two programs representing the same algorithm using two different languages---in one case, C and another case, Java---create disjoint syntax trees such that matching tokenization algorithms will not detect algorithmic equivalence between languages. Neural embedding approaches achieve cross-language representation but require labeled fine-tuning corpora unavailable in labeled-data-scarce CS-1 settings, and produce dense vectors that cannot enumerate which algorithmic patterns a submission contains---a capability essential for interpretable instructional feedback.

This paper proposes a deterministic, gradient-free framework for cross-language algorithmic similarity in CS-1 educational settings, covering C, C++, and Java. Context Normalization Protocol---a cross-language label unification process applied to Code Property Graph (CPG) nodes—our framework makes it possible to perform direct comparisons between patterns irrespective of language without any form of learned alignment. An extended 21-pattern Computation Evolution Signatures (CES) taxonomy, comprising pattern-level descriptors of variable evolution within loops and recursive calls, covers CS-1 imperative strategies across all three languages.  An asymmetrical Tversky formulation compensates for Java’s innate verbosity by assigning a low weight to irrelevant patterns submitted by the students while retaining the ability to capture necessary reference strategies. The framework is able to enumerate the algorithmic patterns present in every submitted code without using GPUs and labeled fine-tuning data.

Under matched held-out evaluation, the model attains 88.75\% top-1 recall accuracy, whereas the neural baseline achieves 71.37\%, highlighting the model’s effectiveness in scenarios where labeled data for fine-tuning is lacking. On the entire 400-program cross-language evaluation task, the aggregate cross-language retrieval accuracy is 87.25\% ($n=400$, all directions); the Java$\rightarrow$C/C++ cross-frontend direction, which constitutes 35\% of evaluation pairs, attains 91.43\% ($n=140$). The remaining 61.5\% of pairs share the C/C++ parser frontend. \textcolor{blue}{The aggregate performance is primarily driven by the Java$\rightarrow$C/C++ and C$\leftrightarrow$C++ directions; the remaining directions are underpowered and detailed in Section~\ref{subsec:cross_lang_results}, indicating that the aggregate score does not imply symmetric cross-language performance.} Feature weights are estimated using only monolingual C code without retraining ($p{<}0.0001$ compared to a TF-IDF benchmark). All reported results are scoped to CS-1 imperative algorithmic problems within a single-institution dataset ($N{=}400$); the hand-crafted taxonomy and rule base intentionally trade scalability for interpretability, and external generalizability requires \textcolor{blue}{multi-institution validation}. Artifacts: \url{https://github.com/Abhinav-C-Das/ckg-multiview-code-similarity}.
\end{abstract}
