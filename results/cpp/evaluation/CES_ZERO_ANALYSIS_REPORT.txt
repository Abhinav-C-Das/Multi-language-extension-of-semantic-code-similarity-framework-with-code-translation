RECOMMENDATIONS FOR CES v3 ENHANCEMENT
================================================================================

New patterns to add to CES v3:

1. DIRECT_FORMULA
   Implementation: Detect direct computation without loops
   Pattern: Single return statement with formula

2. HEAD_RECURSIVE
   Implementation: Detect recursion with computation on return
   Pattern: return value + recursive_call(n-1)

3. HELPER_FUNCTION_PATTERN

4. STL_ALGORITHM
   Implementation: Enhance detection of std::accumulate, etc.
   Pattern: std::algorithm_name(...)

5. TAIL_RECURSIVE
   Implementation: Detect recursion with accumulator parameter
   Pattern: function(params..., accumulator) with recursive call
