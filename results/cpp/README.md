# C++ Code Similarity Baseline Results

## The C++ Dataset Profiles
Because the raw `data/` folder is strictly ignored to manage repository constraints, this document explains the exact parameters of the data processed in this specific C++ pipeline.

The C++ dataset establishes the true **baseline** for our semantic evaluation framework. 
*   **Total Problems:** 20 fundamental algorithmic challenges (e.g., Bubble Sort, Breadth-First Search, Power Sums, Matrix Manipulations).
*   **Total Programs:** N=400 independently sourced student implementations aggregated from established academic code-contest structures (e.g. Codeforces, LeetCode).
*   **Reference standard:** Each problem was evaluated against hardened, verified reference solutions to track deviation without reliance on perfect syntactic matching.

## The Results Explained
Inside the `evaluation/` directory, you will find:
*   `matrices/` - The raw algorithmic correlation values (CES, WL, Baseline) generated by testing every student's C++ submission against the reference files.
*   **Metrics Generated:** The system inherently verifies Abstract Syntax Tree (AST) comparisons alongside our novel Contextual Execution State (CES) parameters.
*   **C++ Specific Context:** The framework flattens C++'s unique raw pointer and memory address mutations into universal execution states, proving that high-level pointer manipulation does not break the symbolic structural similarity view.
